# Holomorphic-VIS

**Высокопроизводительный вычислительный и графический движок на базе голоморфной динамики и принципов проектирования визуальных систем Ш.-К. Чэна.**

Библиотека объединяет непрерывную аналитическую модель комплексного пространства (\(\mathbb{C}\) и сфера Римана \(\hat{\mathbb{C}}\)) с классической символической алгеброй пространственных отношений.

---

## Архитектура проекта

Проект организован в виде модульного `dub`-пакета на языке **D** с двойным таргетом сборки (нативная динамическая библиотека для **Ruby FFI** и модуль **WebAssembly** для браузера) и модульного фронтенда на базе **ES Modules** и **WebGL2**.

```text
holomorphic-vis/
├── dub.json                  # Конфигурация пакета D (нативная сборка + юнит-тесты)
├── Rakefile                  # Единый оркестратор сборки, тестов и веб-сервера
├── source/
│   └── holomorphic/
│       ├── core.d            # Математическое ядро (@nogc, pure, nothrow)
│       ├── vision.d          # Компьютерное зрение: сегментация, 2D/3D-строки, Cross-Ratio
│       └── capi.d            # C-ABI интерфейс (hv_*) для Ruby FFI и WebAssembly
├── ruby/
│   └── holomorphic_vis.rb    # Нативная Ruby-обертка через Fiddle (FFI)
└── web/
    ├── index.html            # Интерактивный клиент
    └── js/
        ├── wasm_bridge.js    # Zero-Copy мост с линейной памятью WebAssembly
        ├── gpu_shader.js     # WebGL2 GLSL-шейдеры для бассейнов Ньютона
        ├── renderers.js      # Рендереры свечей, индикатора HBI, сплайнов и частиц
        ├── vision_renderer.js# Стерео-анализатор фото и генератор 2D/3D-строк Чэна
        └── main.js           # Контроллер камеры, событий и вкладок
```

## Научная база и прикладные возможности

1. **Символическое зрение Чэна (2D/3D-строки и стерео-параллакс):**
   * Выделение объектов методом связных компонент без аллокаций в куче (`segmentObjects`).
   * Автоматическая генерация символических **2D-строк** и **3D-строк `(U, V, W)`** по серии ракурсов с оценкой высоты объектов над опорной плоскостью через остаточный параллакс.
   * Вычисление **проективного инварианта Мёбиуса** (комплексного двойного отношения 4 точек), устойчивого к наклону камеры.
2. **Конформная камера и линза Мёбиуса ($\operatorname{PSL}(2, \mathbb{C})$):**
   * Плавная навигация с сохранением углов пересечения и локальных пропорций через аналитическую производную $|f'(z)|$ и отсечение асимптотических разрывов (*Asymptote Cut*).
3. **Голоморфный Индекс Бифуркации (HBI):**
   * Финансовый индикатор рыночной энтропии на базе сглаженного потенциала побега орбит в квадратичной динамике $z_{n+1} = z_n^2 + c$.
4. **Диффеоморфные конформные сплайны и бассейны Ньютона (WebGL2):**
   * Маршрутизация кривых без самопересечений и аппаратный расчет фрактальных аттракторов на GPU.
5. **Zero-Copy Batch Engine:**
   * Пакетная обработка массивов координат напрямую в линейной памяти Wasm (**~0.3 мс на 5 000 объектов**).

## Быстрый старт

```bash
rake test       # Запуск встроенных математических тестов D
rake build      # Сборка нативной библиотеки (.dll/.so) и WebAssembly (web/engine.wasm)
rake ruby_demo  # Тест нативного вызова D-кода из Ruby через FFI
rake serve      # Запуск интерактивного веб-стенда (http://localhost:8080)
```

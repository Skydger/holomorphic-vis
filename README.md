# Holomorphic-VIS

**Высокопроизводительный вычислительный и графический движок на базе голоморфной динамики и принципов проектирования визуальных систем Ш.-К. Чэна.**

Библиотека заменяет дискретные эвристики классических UI- и BI-движков непрерывной аналитической моделью комплексного пространства (\(\mathbb{C}\) и сфера Римана \(\hat{\mathbb{C}}\)).

---

## Архитектура проекта

Проект организован в виде модульного `dub`-пакета на языке **D** с двойным таргетом сборки (нативная динамическая библиотека для **Ruby FFI** и модуль **WebAssembly** для браузера) и модульного фронтенда на базе стандартных **ES Modules** и **WebGL2**.

```text
holomorphic-vis/
├── dub.json                  # Конфигурация пакета D (нативная сборка + юнит-тесты)
├── Rakefile                  # Единый оркестратор сборки, тестов и веб-сервера
├── source/
│   └── holomorphic/
│       ├── core.d            # Математическое ядро (@nogc, pure, nothrow)
│       └── capi.d            # C-ABI интерфейс (hv_*) для Ruby FFI и WebAssembly
├── ruby/
│   └── holomorphic_vis.rb    # Нативная Ruby-обертка через Fiddle (FFI)
└── web/
    ├── index.html            # Интерактивный клиент
    └── js/
        ├── wasm_bridge.js    # Zero-Copy мост с линейной памятью WebAssembly
        ├── gpu_shader.js     # WebGL2 GLSL-шейдеры для бассейнов Ньютона
        ├── renderers.js      # Рендереры свечей, индикатора HBI, сплайнов и частиц
        └── main.js           # Контроллер камеры, событий и вкладок
```

## Научная база и прикладные возможности

1. **Конформная камера и линза Мёбиуса ($\operatorname{PSL}(2, \mathbb{C})$):**
   * Плавная навигация (панорамирование вдоль оси времени и фокусировка) с сохранением углов пересечения и локальных пропорций объектов через аналитическую производную $|f'(z)|$.
   * **Asymptote Cut:** Аналитическое отсечение разрывов при переходе кривых через полюс $z_{pole} = -d/c$ на бесконечность.
2. **Голоморфный Индекс Бифуркации (HBI):**
   * Финансовый индикатор рыночной энтропии на базе потенциала побега орбит в квадратичной динамике $z_{n+1} = z_n^2 + c$, где $c = \Delta P + i \cdot V$. Детектирует фазовые переходы и слом тренда при пересечении фрактальной границы Жюлиа.
3. **Диффеоморфные конформные сплайны:**
   * Маршрутизация пучков кривых без самопересечений и схлопывания углов при любых деформациях пространства.
4. **Мультикластерная сегментация Ньютона ($z_{n+1} = z_n - \frac{P(z_n)}{P'(z_n)}$):**
   * Аппаратный расчет фрактальных бассейнов притяжения на GPU (WebGL2, 100 итераций/пиксель) для разбиения пространства на произвольное число семантических кластеров.
5. **Zero-Copy Batch Engine:**
   * Пакетная обработка массивов координат напрямую в линейной памяти Wasm (`hv_transform_batch`) без аллокаций в куче (**~0.3 мс на 5 000 объектов** в браузере, **~0.02 мс** в нативном D).

## Быстрый старт

### Требования
* **LDC2** (LLVM D Compiler) с поддержкой таргета `wasm32-unknown-unknown-wasm`.
* **DUB** (пакетный менеджер D, идет в комплекте с LDC2).
* **Ruby** 3.0+ (стандартные модули `rake`, `fiddle`, `webrick`).

### Команды управления (через `Rakefile`)

* **Запуск встроенных математических тестов D:**
  ```bash
  rake test
  ```
* **Сборка нативной библиотеки (`build/holomorphic_vis.dll/.so`) и Wasm (`web/engine.wasm`):**
  ```bash
  rake build
  ```
* **Тест прямого вызова D-кода из Ruby без браузера (FFI):**
  ```bash
  rake ruby_demo
  ```
* **Запуск интерактивного веб-стенда (`http://localhost:8080`):**
  ```bash
  rake serve
  ```
